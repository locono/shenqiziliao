# 神奇资料

神奇资料（shenqiziliao.com）是一个面向公务员考试与研究生入学考试备考人群的资料导航网站。网站把考公、考研相关的课程目录、笔记网盘群和更新动态集中到一处，帮助备考用户快速找到自己需要的资料，不用在多个平台之间来回跳转。

## 网站内容

- **考公课程目录**：公务员、国考省考、教师、事业编、文职、三支一扶、社工、英语、财会、司法等分类
- **考研课程目录**：英语、数学、政治、管理类联考、专业课、笔试、冲刺、押题、复试等分类
- **免费笔记网盘群**：考公、考研笔记资源，持续更新
- **课程更新日志**：查看课程与资源的最新更新动态
- **公众号与联系 QQ**：页尾展示「花生考公」「考研网盘」两个公众号二维码，并提供对应 QQ（点击号码即可复制）

## 页面功能

- 顶部导航栏：左侧为网站 logo 与名称，中间为课程目录等文字入口，右侧显示当天日期
- 主视觉区：网站名称大标题与醒目的域名展示（shenqiziliao.com）
- 资料入口卡片：考公、考研、网盘群、更新日志四大板块，附细分分类标签
- 悬浮按钮：浏览页面时可一键返回顶部
- 自适应布局：手机、平板、PC 不同设备均可正常浏览

## 技术说明

- 纯静态单页网站，只有一个 index.html，二维码图片已内嵌，无外部依赖，无需服务器
- 可直接部署到 Cloudflare Pages：登录 Cloudflare → Pages → 创建项目 → 上传 index.html → 部署完成即可访问
