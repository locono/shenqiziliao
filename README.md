# 神奇资料

神奇资料（[shenqiziliao.com](https://shenqiziliao.com)）是一个面向公务员考试与研究生入学考试备考人群的资料导航网站。网站把考公、考研相关的课程目录、笔记网盘群和更新动态集中到一处，帮助备考用户快速找到自己需要的资料，不用在多个平台之间来回跳转。

## 网站内容



* **考公课程目录**：公务员、国考省考、教师、事业编、文职、三支一扶、社工、英语、财会、司法等分类

* **考研课程目录**：英语、数学、政治、管理类联考、专业课、笔试、冲刺、押题、复试等分类

* **免费笔记网盘群**：考公、考研笔记资源，持续更新

* **课程更新日志**：查看课程与资源的最新更新动态

* **公众号与联系 QQ**：页尾展示「花生考公」「研料库考研」两个公众号二维码，并提供对应 QQ（点击号码即可复制）

## 页面功能



* 顶部导航栏：左侧为网站 logo 与名称，中间为课程目录等文字入口，右侧显示当天日期

* 主视觉区：单栏左对齐，超大标题 + 荧光标注、简短副标题，右侧留白收紧；域名收于页尾超大描边字

* 资料入口卡片：考公、考研、网盘群、更新日志四大板块，附细分分类标签

* 悬浮按钮：浏览页面时可一键返回顶部

* 自适应布局：手机、平板、PC 不同设备均可正常浏览

## 视觉风格

* 暖纸白底 + 极细网格纸纹，墨黑文字，电光蓝 / 荧光柠檬黄 / 朱红三色点缀，整体明亮清新

* 编辑式（editorial）排版：左对齐超大标题、等宽数字编号、竖排边注、章节标尺（编号 + 英文标签）、紧凑的垂直节奏

* 资料入口改为「档案抽屉」卡片：硬阴影、侧边色标、错落排布，悬停时抽出上浮

* 二维码区为荧光黄票据版式；两张二维码均为约 2.74:1 的横幅长图（花生考公 900×328 PNG、研料库考研 1710×624 JPEG），按各自原始比例完整展示，不裁切不变形

* 动效克制：滚动入场、悬停位移，遵循 `prefers-reduced-motion` 自动关闭

## 技术说明



* 纯静态单页网站，只有一个 index.html，二维码图片已内嵌，无外部依赖，无需服务器

* 可直接部署到 Cloudflare Pages：登录 Cloudflare → Pages → 创建项目 → 上传 index.html → 部署完成即可访问
